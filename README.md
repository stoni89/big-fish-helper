# Big Fish Helper

Helps you catch Big Fish in FINAL FANTASY XIV, working together with
[AutoHook](https://github.com/PunishXIV/AutoHook) (required).

Custom Plugin Repository URL (Dalamud → Settings → Experimental → Custom Plugin Repositories):

```
https://raw.githubusercontent.com/stoni89/DalamudPlugins/main/repo.json
```

Open the menu with `/bigfish`.
